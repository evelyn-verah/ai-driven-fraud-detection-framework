# Data directory

## Included dataset

`synthetic/synthetic_transactions_5000.csv` contains 5,000 **synthetic** transactions generated by `make_synthetic(n=5000, seed=42)` in `src/fraud_detection/pipeline.py`. The `is_fraud` labels are artificially generated from explicit rules in that code. This dataset is for engineering tests only, not evidence of real-world fraud detection effectiveness.

Fields: `transaction_id`, `amount`, `hour`, `transactions_last_hour`, `device_changed`, `failed_logins_24h`, `channel`, `is_fraud`.

## Real datasets

No real payment transaction dataset is bundled. Add an appropriately licensed and reviewed CSV to `data/raw/` (create that folder as needed). For the generic baseline, the target column must be `is_fraud` with 0/1 labels. Dataset-specific preparation and leakage checks are required before drawing research conclusions.
